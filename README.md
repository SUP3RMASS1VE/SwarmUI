# SwarmUI

A Windows pinokio script for https://github.com/mcmonkeyprojects/SwarmUI

You may get a blue error screen after installation is done, Dont worry its not an error it is just because you need to finish the installation on the WebUI. Once done it will run fine with no blue screen.

Install DotNET 8 SDK before installing from https://dotnet.microsoft.com/en-us/download/dotnet/8.0 (Make sure to get the SDK x64 for Windows)
